# Statistical Computing and Data Analysis

This repository contains a collection of statistical programming and data analysis projects completed using Python and R. The projects involve working with real-world datasets, cleaning and transforming data, creating visualizations, developing custom functions, and applying statistical methods to explore relationships and trends.

## Projects

### College Scorecard Analysis
Analysis of higher education data using Python and R, including comparisons of student debt, completion rates, and institutional characteristics. Includes statistical visualizations and custom functions for comparing institutions.

### U.S. Mortality Data Analysis
Processing and analysis of 2024 mortality data, including converting coded variables into meaningful categories, handling missing values, and visualizing patterns across demographic groups.

### Regression Modeling and Diagnostics
Application of regression models, statistical inference, and diagnostic methods to examine relationships between variables and evaluate model assumptions.

## Tools and Technologies

- **Python:** Pandas, NumPy, Matplotlib
- **R:** ggplot2, dplyr, R Markdown
- **Statistical Methods:** Exploratory data analysis, regression, descriptive statistics, hypothesis testing, and data visualization

## Repository Organization

Each project is organized into its own folder containing code, analytical results, and supporting documentation where applicable.
