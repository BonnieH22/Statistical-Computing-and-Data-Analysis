01 / DATA PREPARATION & VALIDATION

2024 Mortality Data Analysis

This analysis uses 2024 mortality records to demonstrate transforming coded variables into understandable categories and checking the transformed data through exploratory visualizations.

The original data contained numeric and cause-of-death codes. I created functions to convert these into categories for intent, race, education, and place, and to convert recorded ages into a format suitable for analysis. I then created a new dataset with selected variables including year, month, intent, sex, age, race, place, and education.

Interpretation from the homework: The plots from my decoded data and the mortality data used in the earlier homework had roughly the same distribution for both sexes, with some minor differences. The additional plots from the decoded dataset were nearly identical to those generated from the comparison dataset. This suggested that the conversion was generally successful; visual similarity alone does not prove every record was recoded correctly.

These charts report counts, not rates adjusted for the size of demographic populations. They should not be interpreted as comparisons of individual risk.

02 / CUSTOM VISUALIZATION FUNCTION

College Scorecard Comparisons

I developed a reusable R function for comparing an individual institution with a distribution of other colleges using the 2023–24 College Scorecard data.

The function creates multipanel histograms for admission rate, completion rate, tuition, and enrollment. A red vertical line identifies the selected institution. The comparisons can optionally be restricted to institutions with the same control type or institution level; the set of displayed variables can also be changed.

An institution’s position depends on which other colleges are included in the comparison. The function uses separate completion-rate variables for four-year and shorter programs where applicable.

03 / DATA AGGREGATION & COMPARISON

Graduate Earnings by Institution and Field of Study

The custom major_salary analysis uses College Scorecard field-of-study data to compare reported median earnings four years after completion across institutions, majors, and credential levels.

I developed a function that accepts selected institutions and majors, supports different credential levels, and can include reference values for all majors, individual majors across colleges, or all majors at a specified institution. The function returns a summary table and a horizontal bar chart.

These figures show the College Scorecard earnings measure used in the assignment. They are descriptive comparisons—not causal estimates of the effect of attending a particular institution or choosing a major. Available earnings data may vary by program.
